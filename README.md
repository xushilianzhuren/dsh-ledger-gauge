# dsh-ledger-gauge · 读数台（插件）

把「读数纪律」写成常驻条款，并给一屏能看的台账全貌。

## 为什么原生读账

度量族主力件（`RSI成本账.py`、`E17价值凝固.py`、`存在面采集器.py`）都写死 `<workspace>`，
跑不动；但台账本身在盘（47 本 `.jsonl`）。所以本插件直接扫台账：条数、最后一条时间、体量。

## 区块 `ql:gauge`（默认排序 120）

三层读数（实测＞估算＞未知）＋读数四件套（值／出处／时点／复验命令）＋账本即读数（久不增＝没在跑）＋过期即腐＋判据（能不能当场重跑）。

## 工具 `ql_gauge`

| action | 干什么 |
|---|---|
| `台账面` | 扫 `scripts/`、`scripts/裁撤归置/`、根目录全部 `.jsonl`，按最后一条时间倒序出前 25 本（条数／KB／路径） |
| `台账查` | 按台账名关键词，出命中台账的条数与末三条 |

只读，不写任何文件。

## 配置

| 字段 | 默认 | 含义 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `order` | `120` | 区块排序 |
| `tool` | `true` | 是否挂工具 |
| `root` | 自动 | 工作区根 |

## 诚实边界

- 只统计"行数"，不判"行对不对"：台账里可以是坏行、重复行、半行。
- 最后一条时间取常见字段（时/时间/ts/t/日期/date/time），取不到就退回文件 mtime——mtime 会被拷贝/解压刷新，不等于真写入时间。
- 台账条数不是业绩：只增不查的账＝记了白记，这一点工具判不了，得靠人。
